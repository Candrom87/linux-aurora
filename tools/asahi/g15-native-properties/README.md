# Original native property views

Synthetic copied ADTs exercise the actual parser, duplicate and complete-name
checks, count/scalar bounds, optional SRAM and retained property extensions.
Every proper prefix of a valid tree is refused. Returned spans must remain
inside their owner. No mapping, device or private input is read.

```sh
python3 -B tools/asahi/g15-native-properties/check.py --mutants --receipt /tmp/properties.json
```
